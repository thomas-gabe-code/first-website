HTML & CSS Cheat Sheet

Don't try to memorize this stuff.

Just find what you want to do, copy the example, and change it however you want.

HTML — Adding Stuff

I want to... Add a heading Add normal text Add a link Add an image Make a list Make a button

Add a Heading

Use:

<h1>My Heading</h1>

That creates:

My Heading

You can also use h2, h3, h4, etc. Smaller numbers generally mean more important/larger headings.

Add Normal Text

<p>This is some text.</p>

This is some text.

Add a Link

<a href="https://google.com">Go to Google</a>
Go to Google

Whatever goes inside href="" is where the link goes.

Add an Image

First put the image inside the images folder.

Since this page is inside the pages folder, use: 

<img src="../images/jpork.jpeg" width="300">

Change the filename to whichever image you want to use.

Make a List

<ul>
    <li>Pizza</li>
    <li>Video Games</li>
    <li>Music</li>
</ul>
  • Pizza
  • Video Games
  • Music

Make a Button

<button>Click Me</button>

This makes a button, although you'll eventually need JavaScript if you want clicking it to actually do something interesting.

CSS — Changing How Stuff Looks

HTML adds things to the website. CSS changes how those things look.

I want to... Change text color Change the background color Make text bigger or smaller Center text Add a border Add space around something

Change Text Color

color: red;

For example, you could put this in style.css: 

h1 {
    color: red;
}

Now every <h1> will be red.

Change the Background Color

background-color: lightblue;

For the entire website:

body {
    background-color: lightblue;
}

Change Text Size

font-size: 30px;

For example:

p {
    font-size: 20px;
}

Center Text

text-align: center;

For example:

h1 {
    text-align: center;
}

Add a Border

border: 2px solid black;

For example:

img {
    border: 2px solid black;
}

Add Space Around Something

Padding adds space inside something. 

padding: 20px;

Margin adds space outside something. 

margin: 20px;

Most Important Rule

You don't need to know all of this.

Try something. Save the file. Look at what happened. If you don't like it, change it again.
